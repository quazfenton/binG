          // Called by the runtime when the SSE consumer (browser /
          // curl / EventSource) disconnects. By the time cancel()
          // runs, request.signal has already fired `abort` so
          // config.abortSignal is `aborted: true` for any execution
          // mode that checks it on its next reactive poll. We just
          // record the disconnect here as signal-class telemetry.

          // automatically per WHATWG, so the client sees [DONE]
          // immediately — no explicit controller.close() needed.

          // start() keeps running server-side until it honors
